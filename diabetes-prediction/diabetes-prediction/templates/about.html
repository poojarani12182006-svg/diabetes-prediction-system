About the project

How GlucoSense goes from raw data to a live prediction

This is an end-to-end applied machine learning project: a public medical dataset, a preprocessing and model-comparison pipeline, and a Flask web application that serves the trained model.

  • Data collection

    The Pima Indians Diabetes Dataset — 768 records of female patients of Pima Indian heritage, aged 21+, with 8 diagnostic measurements and a binary outcome.

  • Data cleaning

    Physiologically impossible zero-values in Glucose, Blood Pressure, Skin Thickness, Insulin, and BMI are treated as missing and replaced with the column median.

  • Train / test split & scaling

    An 80/20 stratified split preserves the class balance. Features are standardized with scikit-learn's StandardScaler before training.

  • Model training & comparison

    Logistic Regression, Decision Tree, and Random Forest classifiers are trained on the same data and evaluated on accuracy, precision, recall, and F1-score.

  • Model selection

    The model with the highest F1-score is chosen automatically — F1 balances false positives and false negatives, which matters for a health-related prediction.

  • Serialization

    The winning model and the fitted scaler are saved with Joblib so the exact training-time preprocessing is reused at prediction time.

  • Web deployment

    A Flask backend loads the saved model and scaler once at startup, validates incoming form data, and returns a prediction with a confidence score.

Tech stack

Python Pandas NumPy Scikit-learn Matplotlib Flask Joblib HTML / CSS / JS

Dataset details

Source: National Institute of Diabetes and Digestive and Kidney Diseases

Records: 768 patients

Target: Outcome (1 = diabetic, 0 = not diabetic)

Important limitations

This model is trained on a specific population (adult women of Pima Indian heritage) and a relatively small dataset. It is built for educational purposes to demonstrate a full ML + web deployment workflow, and its predictions should never be used for real medical decisions.
